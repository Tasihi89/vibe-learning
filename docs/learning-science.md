# 为什么学习页这样设计

学习者主动问，每个回答配一张图。下面是设计背后的证据，标「现在没做」的是有证据、但试过嫌复杂没留下的。想改设计时先看这里；想加新做法，先找证据，再问学习者要不要。

| 做法 | 证据 | 学习页里怎么用 |
|---|---|---|
| 学习者自己提问，跟着好奇心走 | Chi & Wylie 2014 ICAP：主动、建构、互动的投入比被动接收学得多（后续证据有正有反，但方向一致）；Rosenshine 等 1996 综述：教学生自己提问能提高理解 | 页面不预设讲义，只有几个起步问题作参考 |
| 同一个概念用多种表征 | Ainsworth 2006 DeFT 框架：多种表征能互补、互相约束理解、帮助抽象和迁移；前提是学习者能把它们对上 | 每个回答挑一种最合适的图；想换个看法就接着问 |
| 图文结合、有信号、去掉无关内容 | Mayer 多媒体学习原则：多媒体、空间接近、信号、连贯（删无关内容）、分段，效果中到大 | 先一两句直接回答，再上图；一般一张图，最多两张；文字不超过四句 |
| 一页一页往上搭，最后才总结 | Mayer 多媒体学习原则里的分段原则（把连续的讲解切成学习者自己控制节奏的小段）和预训练原则（先认识关键零件叫什么、干什么，再看它们怎么一起动） | 有先后的事一步步翻：每页只多一个变化，最后一页是完整的图，规律放到最后收 |
| 边讲边画：字挨着它讲的那部分图、同时出来，同一句话不说两遍；一页是一个有意义的变化 | Mayer 多媒体学习原则里的空间接近、时间接近（字和对应的图挨着、同时出现）、冗余（同样的话在两处出现反而学得少）、分段（按意义切成学习者自己翻的小段，Mayer 和 Chandler 2001 的闪电动画一段就是因果链上的一步）；Sweller 等的注意力分散效应：要在两处之间来回对照，费的劲挤掉理解；Fiorella 和 Mayer 2016：看老师边讲边画，比看画好的图学得好 | 翻页的图：翻一页出一个变化，讲它的话画在图里、挨着它，图上面不放说明，翻过去的话变淡（见 `answer-spec.md`「一步步翻」） |
| 概念图 | Nesbit & Adesope 2006：看概念图比看文字好（约 0.4 个标准差），自己参与构建更好（约 0.8） | （现在没做）试过基础图、关联和全景，嫌复杂 |
| 在已有知识上接新知识 | Merrill 2002 首要教学原则：先唤起已知 | 每次提问都带上最近 5 个问答，回答接着他已经知道的讲 |
| 做题回忆比重读有效 | Dunlosky 等 2013：只有做题回忆和间隔练习被评为高效；重读、划线、写总结低效；Adesope 等 2017：检索练习平均 g≈0.6 | （现在没做）以后加复习时用 |
| 自己解释 | Bisra 等 2018 元分析：g≈0.55 | 复述：他在单独一页里用自己的话讲，原来的回答不在眼前 |
| 直面误区 | 反驳式讲解的元分析：g≈0.41（Educational Psychology Review 2021）；Danielson 等 2025 预注册元分析结论一致 | 复述：AI 把他讲的模型画出来，错的标红、写对的说法，再画改过来的那张 |
| 隔几天再练 | Cepeda 等 2008：最佳间隔随要记住的时长变长，间隔太短比太长损失大 | （现在没做）以后加复习时用 |
| AI 导师要有护栏 | Kestin 等 2025（哈佛物理课 RCT）：一步一步引导的 AI 导师收获是课堂主动学习的两倍以上；Bastani 等 2025（PNAS）：不受限的 GPT 练习时成绩高，撤掉后考试反而低 17%，学生还觉得自己学会了 | 提问时直接回答（学习者在探索）。以后加复习时：先让学习者自己说，再判断、指误区、追问，不先给答案 |

## 用的时候注意

- 效应量来自不同研究和人群，只说明方向和大致强弱。
- 多种表征不是越多越好：学习者要能把几张图对上。所以每次一张，最多两张。
- 学习者的「我懂了」不可靠，以复述的判断为准。
