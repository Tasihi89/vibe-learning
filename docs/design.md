# 设计记录

Vibe Learning 的页面和回答为什么是现在这样。多数是在真实使用里看了效果以后定下来的。改页面前先看这里，别把试过、去掉了的东西加回来。

## 是什么

一问一答。学习者问，AI 回答。目的是帮他在脑子里搭起模型：有哪几样东西、怎么连、背后哪条规律，搭好了他能自己推、能预测。可视化是手段，每个回答都把这个模型画出来。图由 AI 自己设计（SVG），形式不限，不套固定格式；不做可以点、可以拖的交互图（太慢）。

**少就是好。** 基础图、概念图、全景、关联、换个角度、复习、做题、学习路径、标签页，都试过，嫌复杂，去掉了。加功能前先想能不能不加。留下来的是：备注、标记、目录、地图、页的颜色、首页、复述。

**页面上不放操作说明。** 「Enter 发送……」「点一个就跳过去……」这类提示都删掉了，只留状态（连接中、连不上、正在回答、回答中断了）。新用户怎么用，由装它的 Claude 和 `README.md` 讲；首页一个项目都还没有时，输入框下面放三个能点的问题，它们是内容，不是说明，开过一个项目就不再出现。

## 首页和开新项目

打开就是首页：最上面「Vibe Learning」，下面一个大输入框「想学什么？」，再下面是学过的项目（项目名、最后问的问题、问了几个、多久以前），最近问过的在前；最下面是「思维模型」（见「复述」）。

写一句话就开一个新项目：服务马上建好项目，页面跳进去开始回答这句话；同时后台让 AI 照 `topic-spec.md` 起标题、写底稿、找几个材料来源、想三个可以接着问的问题，写好了页面上的标题自己换掉，不用刷新。项目页左上角的小房子回首页。

**删项目**：鼠标移到卡片上，右下角出一个灰字「删除」；点一下变成红字「确定删除」，再点才删，点到别处或过 5 秒恢复。删掉的项目挪进数据目录的 `_deleted/`，不是真删；正在给它开题、回答的 AI 一起停掉。

**怎么打开**：就在浏览器里用网页，不做成有自己窗口的应用（网页更轻）。Mac 上有一个「Vibe Learning」图标（`mac/make-app.mjs` 做的），点它等于运行 `node serve.mjs`，不用开终端。应用的名字以后不改：改名会让用户桌面上、程序坞里的快捷方式失效。

## 学习页

像文档编辑器：中间是问答，右边是备注栏，左边是目录。没问过问题时，显示几个可以问起的问题。

在回答里选中一段，出一个小工具条：

- **问 Claude**：这段划上线，侧栏出一张备注卡片，在卡片里问，回答也在卡片里（更短）。卡片对齐它引用的那段；点划线的文字，卡片点开，可以接着追问；单击卡片，展开成整页。
- **标记**：像荧光笔一样标黄，存下来。回答和自己的问题都能标。点一处标记，可以取消，或者拿它加备注。

每条备注也是一页，样子和开头那一页一样，底下接着问，里面选中文字还能再加备注。备注能删，和删项目一样要点两下；下面还挂着备注时写「连下面 N 条备注一起删」。删掉的挪进 `_deleted/<项目>-备注/`。

**顶栏**只放小房子（回首页）、「返回」、项目名（点了回开头那一页）和「地图」。「返回」：往深处走一次（展开备注、开复述、从地图跳过去）记一步，点它退回原来那一页、原来滚到的地方；退到头带人回进来之前那一页。往上走（目录、标题）不多记步，免得来回绕。

**左边的目录**：只列页，一页一行，备注页挂在它出自的那一页下面、往右缩一格。这一页浅蓝底蓝字，标了色的页行末一个小色点。一种字体、一种字号，层级只靠缩进。

**跟着窗口大小变**：窗口比 1440 宽时，问答区、目录、备注卡片、输入框一起等比放大，最多 1.3 倍。

**地图**：一页一块，从左往右长，块里按先后一行一个问题；点一行跳过去。

**页的颜色**：重点的备注页可以标颜色，18 种淡色（黄色留给标记）。

**输入框**：一个圆角的整体，右下角一个圆按钮（向上的箭头）。没写字时按钮是灰的；正在回答时换成「停止」。

## 复述

想检查自己是不是真懂了某一块，就用自己的话讲一遍。

- **只有一个作用**：把他脑子里的模型画出来，和正确的对比，把想错的地方改过来。不打分、不推题、不提醒，之后怎么问、怎么聊不限制。
- **从白框开始**：每个回答的白框右上角有一个图标（对话气泡里一个绕回来的箭头），鼠标移上去才出来。复述过的白框，图标一直显示、带蓝色。点它：复述过就打开那一页，没复述过就开一页新的。
- **复述是单独的一页**，那一页里看不到原来的回答（凭记忆讲才有用）。最上面有「看原回答」，点了回到那个白框、闪一下。复述页和备注页一样：底下接着问，能问 Claude、能标记、能标颜色。
- **范围不用选**：页面把这个回答、它一路的来路、同一页里它前面的问答都给 AI，他讲多少，AI 就对比多少。
- **复述合集**：顶栏「地图」旁边的「复述」（有过复述才出现），一次复述一张卡片。
- **收进思维模型**：复述页里 AI 画的每张图，右上角有一个书签图标，点了收进首页的「思维模型」，再点取消。
- **AI 怎么答**（`answer-spec.md`「复述」）：先画「你讲的模型」，照他的说法和结构画，讲错的标红并写对的说法，漏掉的画成虚线空框；再在他那张上改出正确的模型，改的地方用黄色点出来。都讲对了只画他那一张。

## 回答

回答格式只有一份：`answer-spec.md`。先想清楚要搭什么模型、他现在缺什么、和之前的画面怎么接，再一两句说出那条规律，配一张自己画的图（实在讲不清才两张），文字不超过四句。他是来学概念的：真术语都要出现，每个跟一句大白话；图上的字写成完整的句子，不压缩成「其他 → 路由器」这种暗号，也不拿比喻顶替术语。

回答格式和发给 AI 的材料里，不写要不要读文件、要不要上网查，让它自己安排。

**有先后的事，一步步翻。** 一张图把好几步全摆在一起，人不知道先看哪。所以讲的是有先后的事（一个过程、一行代码背后发生的几件事、东西一路怎么走），或者图上东西超过三四样，就一页页翻，最后一页是完整的图。为了不变慢，AI 只画一张完整的图，图里每样东西标 `data-step`（从第几页出来），页面翻到哪页亮到哪；每页画一张要多等半分钟到一分钟，没选。新出来的东西加一圈只在这一页出现的黄色。

**边讲边画。** 字和图分在两处、同一件事讲两遍，人得理解两遍；一页一下出来太多东西又跟不上。所以：

- 一页是一个变化：一句话说得完的「发生了什么」，为它服务的几样一起出（不按一个框、一根箭头拆，太碎）；新的慢走，熟的快走。
- 讲它的话画在图里，挨着那个变化，和它一起出来；图上面不放说明。图里的话包在 `data-say` 里，翻过去变淡。翻到最后，图里的话从上读到下就是完整的讲解。
- 一句话只说一次：箭头和框上只写动作或名字，旁边的话讲是什么、为什么。
- 从熟的接到新的，说清它是什么、什么时候发生，不只说「不」。

学科、原理这类，讲通用的道理；不主动把话题扯到他电脑上的设置、在用的软件或别的学习项目上，他问到自己的电脑时才去看。

## 页面里的 AI

页面把问题发给服务，服务调本机的 `claude -p`，用学习者自己 Claude Code 的登录和额度。不读 CLAUDE.md、技能和 MCP（`--safe-mode --strict-mcp-config`），在项目目录里运行。

- **能做的**：上网查；读这个项目的文件夹和 `topic.json` 里 `sources` 写的路径；往这个项目的 `files/` 里写。
- **不能做的**：运行命令；写 `files/` 以外的地方；默认读不到电脑上别的文件。
- **为什么默认只读项目文件夹**：它会上网读网页，网页里可能藏着骗 AI 的指令。只读得到项目文件夹，就算被骗也拿不到别的文件。想让它讲自己电脑上的代码、软件，在数据目录的 `settings.json` 里写 `{"readAnywhere": true}`，整台电脑都读得到。

回答是流式显示的：文字边写边出，图随着内容到达一步步画出来（模板里的 `repair` 把还没写完的 JSON 补全了先画）。它查资料时，页面上显示「在读 xxx」「在网上搜 xxx」。

它没有记忆。每次提问，页面把这些一起发过去：学习者是谁、项目、资料在哪、底稿、回答格式、这一页是怎么一路长出来的、这一页最近 5 个问答、是不是在备注卡片里问的，和问题本身。

只有一档：Opus，思考力度 high。实测：xhigh 一个问题要三四分钟；high 一般 25 到 40 秒答完，要上网查资料时一分多钟；medium 只快几秒，却常把 JSON 写坏（第一段写成普通文字，或者 SVG 里的引号没转义），页面就丢字、丢图；low 也写坏。

页面用的开源库（marked、DOMPurify、KaTeX）放在 `vendor/`，从本机服务取，不从 CDN 取：网络连不上 CDN 时页面照样能用。

## 课程（公开版不带工具）

页面还认「课程项目」：一集视频课一个项目，开头那一页放这一集的笔记，笔记里的时间能点，视频浮在右下角。做课程项目的工具不在公开版里，`schema.md` 里的 `course`、`lesson` 字段是给它用的。
